The plugin invokes ffmpeg as a separate executable for decoding, encoding and
basic filtering. It does not link FFmpeg libraries into the plugin code.

If you redistribute this package, keep this notice and comply with GPLv3
(including making the corresponding source available). To use a different
FFmpeg build, set DSH_VOICE_FFMPEG to its path and remove bin/ffmpeg.exe.
