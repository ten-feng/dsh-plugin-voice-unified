# 最低与推荐硬件配置

本插件默认是 CPU 本地 DSP，不要求 GPU。以下为 Windows 10/11 x64 实测与估算。

## 最低配置

| 项目 | 要求 |
|---|---|
| CPU | 4 核 x64（Intel i5 或同级） |
| 内存 | 8 GB（DSH + 插件 + 浏览器） |
| 磁盘 | 2 GB 可用（插件含 43MB ffmpeg；音频与样本另计） |
| 音频 | 任意可播放系统声音的输出设备；录音/上传样本不需要麦克风 |
| GPU | 不需要 |
| 网络 | 仅首次安装 / 模型对话需要；TTS、训练、翻唱默认离线 |

## 推荐配置

| 项目 | 建议 |
|---|---|
| CPU | 6 核 12 线程（如 i5-10400 / Ryzen 5 3600） |
| 内存 | 16 GB |
| 磁盘 | 10 GB+ SSD（多音色、多版本、长翻唱） |
| GPU | 非必需；接神经 TTS/RVC 外部引擎时建议 NVIDIA RTX 2060 6GB+ |
| 系统 | Windows 11 + 中文语音包 |

## 性能实测（本机 i5-10400F / 16GB / RTX 2060 SUPER，CPU 路径）

| 操作 | 耗时 |
|---|---|
| 3 秒样本 analyze | < 0.5 秒 |
| 3 样本训练 + 版本试听 + 相似度 | 约 3~5 秒 |
| 一句 10 秒语音 TTS + 变声 + MP3 | 约 2~4 秒 |
| 20 秒歌曲翻唱（分离→换声→混音→MP3/WAV） | 约 3~5 秒 |
| 102 项引擎测试 | 约 1~2 分钟 |

数字随音频长度、CPU、杀软扫描变化。翻唱队列单 worker，长歌曲会顺序排队。

## 存储估算

- 单条 10 秒 24kHz 单声道 WAV：约 480KB。
- 单次语音回复 MP3：约 30~200KB；WAV 约 0.5~2MB。
- 单首 4 分钟翻唱：MP3 约 5~7MB，WAV 约 40MB，中间文件处理完会清理。
- 训练版本只保留试听 MP3/WAV；样本原始文件会保留。

建议定期清理 `audio/covers` 与 `audio/previews` 中不需要的历史文件。
